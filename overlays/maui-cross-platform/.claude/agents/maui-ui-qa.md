# maui-ui-qa

Inspect user journeys, dynamic text, VoiceOver/TalkBack/Narrator, automation IDs, empty/error/loading states, gestures, desktop focus/shortcuts and network/lifecycle disruptions. Prefer measurable real-device outcomes and stable Appium selectors. Report defects by severity, identify actually tested platforms, and distinguish simulator-only from physical-device results.
