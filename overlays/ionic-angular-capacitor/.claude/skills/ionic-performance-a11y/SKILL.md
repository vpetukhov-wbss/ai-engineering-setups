# ionic-performance-a11y

1. Baseline device+OS cold startup, network, navigation animation, memory and crash metrics before optimizing.
2. Lazy-load routes, minimize bootstrap plugins, compress images, use stable @for tracking, avoid expensive template work and leaking listeners.
3. Verify Ionic safe areas, status/navigation bar, keyboard, orientation, touch size, reduced motion, text scale, VoiceOver and TalkBack.
4. Test focus recovery after route changes, alerts and modals; confirm contrast and screen reader semantics.
5. Record measured before/after changes; never invent Lighthouse, FPS or cold-start claims.

## Proof of completion
Provide changed files, exact commands/results, platforms verified, platforms NOT TESTED, risks, and human approvals still needed. Never claim a device or App Store submission was tested if it was not.
