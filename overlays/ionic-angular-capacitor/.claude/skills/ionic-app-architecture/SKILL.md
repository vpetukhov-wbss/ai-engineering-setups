# ionic-app-architecture

1. Inventory locked Angular/Ionic/Capacitor/Node versions, native plugins, toolchains, routes, browser target and package scripts.
2. Translate business requirements into actors, flows, device-specific constraints, data protection, supported OS versions, privacy and acceptance criteria.
3. Compare web/PWA, Ionic+Capacitor, MAUI and fully native only where requirements demand; record tradeoffs and ADRs.
4. Design feature-first Angular routing, state ownership, typed backend contracts, permission and plugin boundaries, offline data classification.
5. Produce rollout slices, native capability matrix, measurable performance targets, security risks and test/release strategy. No speculative micro-layers.

## Proof of completion
Provide changed files, exact commands/results, platforms verified, platforms NOT TESTED, risks, and human approvals still needed. Never claim a device or App Store submission was tested if it was not.
