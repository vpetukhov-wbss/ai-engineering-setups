# Angular Release Checklist

- [ ] Version, lockfile and build environment recorded
- [ ] Unit, integration, contract and critical E2E checks passed
- [ ] Keyboard, responsive and error-state smoke completed
- [ ] Production build budgets and dynamic imports reviewed
- [ ] Client bundles contain no credentials or private content
- [ ] CSP, CORS, secure cookie/XSRF and SSR proxy/cache controls verified
- [ ] SPA rewrites or SSR routing configured correctly
- [ ] Observability, 404, cache invalidation and rollback rehearsed
- [ ] Staging smoke signed off
- [ ] Production release approved by authorized owner
