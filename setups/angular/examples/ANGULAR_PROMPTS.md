# High-value Angular Claude Code prompts

## Architecture
`/angular-architecture Design an Angular application for managing cake orders and production queues backed by ASP.NET Core. Compare CSR vs SSR, feature boundaries, auth/session strategy, API contract, caching, observability and tests. Propose ADRs and phases.`

## Complete feature
`/angular-feature Implement order filtering, status changes and optimistic concurrency handling. Keep TS/HTML/SCSS/spec distinct, type APIs and handle loading/error/empty states; validate keyboard access and run project tests.`

## Code review
`/angular-code-review Review the diff for race conditions, leaking subscriptions, insecure auth assumptions, unnecessary state libraries, slow templates, accessibility and unverified tests. Rank actionable findings.`

## Full stack
`/angular-api-integration Connect the Angular order editor to ASP.NET Core OpenAPI endpoints. Verify auth/XSRF, ProblemDetails, ETag/version conflicts, retry behavior, DTO compatibility and tests.`
