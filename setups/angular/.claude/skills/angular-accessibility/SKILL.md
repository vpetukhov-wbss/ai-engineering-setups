# angular-accessibility

## Procedure
1. Inventory interactive components and journeys, including dialogs, forms, nav, grids, errors and toasts.
2. Use real semantic elements, labels, landmarks, accessible names, visible focus, keyboard support and color contrast.
3. Test tab order, modal focus trap/return, reduced-motion, text zoom and error announcements.
4. Run available automated checks and targeted manual screen-reader checks where possible; do not claim full WCAG compliance from lint alone.
5. Produce prioritized, reproducible findings and tests.

## Deliverables
Summarize scope and choices, changed files, verified commands/results, evidence, risks and required human approvals.
