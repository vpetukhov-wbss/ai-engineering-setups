# angular-forms

## Procedure
1. Select reactive/typed forms or supported modern forms approach based on target Angular version and established conventions.
2. Specify field constraints, cross-field and async rules, submit/disable states, dirty resets, server validation mapping.
3. Ensure accessible labels, field errors, focus on first error, keyboard interaction, busy state and no duplicate submits.
4. Handle optimistic concurrency/version conflicts without silent data loss and protect draft content during navigation.
5. Test success/error, partial input, race/cancel, permission and a11y.

## Deliverables
Summarize scope and choices, changed files, verified commands/results, evidence, risks and required human approvals.
