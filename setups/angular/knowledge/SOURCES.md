# Primary Angular references

This repository synthesizes original engineering guidance from publicly accessible documentation; it is not affiliated with Angular/Google or other cited maintainers. Confirm applicability against the target application version.

- Angular documentation homepage: https://angular.dev/
- Official coding style: https://angular.dev/style-guide
- Angular signals: https://angular.dev/guide/signals
- Angular zoneless: https://angular.dev/guide/zoneless (v21+ defaults to zoneless)
- Angular dependency injection: https://angular.dev/guide/di
- Angular standalone migration: https://angular.dev/reference/migrations/standalone
- Angular routing: https://angular.dev/guide/routing
- Angular HTTP client: https://angular.dev/guide/http
- Angular forms: https://angular.dev/guide/forms
- Angular testing: https://angular.dev/guide/testing (recent CLI projects use Vitest)
- Angular security: https://angular.dev/best-practices/security
- Angular SSR: https://angular.dev/guide/ssr
- Angular update guide: https://angular.dev/update-guide
- TypeScript handbook: https://www.typescriptlang.org/docs/handbook/intro.html
- web.dev Core Web Vitals: https://web.dev/articles/vitals
- W3C WCAG: https://www.w3.org/TR/WCAG22/
- OWASP ASVS: https://owasp.org/www-project-application-security-verification-standard/
- Playwright: https://playwright.dev/docs/intro

Do not infer that every topic was read in its entirety or that the latest framework APIs work on all versions. Do not reproduce paid material.
