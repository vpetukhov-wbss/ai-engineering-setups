# MAUI mobile feature
- Inspect platform targets and installed toolchains; enumerate Android and iOS build limitations before implementation.
- Model native vs Blazor Hybrid choice from requirements; use appropriate MVVM, views, ViewModels and DI lifetimes.
- Define offline behavior and sync/conflict policy, navigation state, retry/idempotency, device permissions and storage.
- Use OS system browser for sign-in and secure storage; keep tokens and backend secrets out of WebView and binaries.
- Implement resilient async flows with cancel/dispose, UI-thread-safe state updates and platform adapters.
- Verify Release/trimming, real device lifecycle, permissions, dark mode, accessibility and slow network.
- Explain provisioning/signing/store publishing requirements; no store release without explicit approval.
- Reference `knowledge/MAUI.md`.
